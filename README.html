🏢 Apartment Management System

Integrated full-stack application with agentic AI workflows for resident management

Project Overview

A comprehensive apartment management platform built with modern full-stack technologies, featuring resident onboarding, maintenance management, facility booking, and integrated agentic AI workflows for intelligent decision-making.

Key Features

  • Resident Management: Register, profile management, vehicle registration, household members
  • Maintenance System: Complaint tracking, AI triage, technician assignment, repair cost validation
  • Facility Booking: Real-time availability, payment integration, invoice generation
  • Smart Payments: Invoice management, payment history, chat-based payment assistance
  • Safety Validation: Multi-layer security checks, role-based access, injection detection
  • AI Onboarding: LLM-powered resident extraction with rules-based fallback
  • Cross-Platform: Web (React) + Mobile (Flutter) + Backend (ASP.NET Core)

System Architecture

The system follows a multi-layered architecture with clear separation of concerns:

Frontend Layer

React Web Application (5180) - Administrative dashboards, resident management, agent approval workflows, safety auditing

Flutter Mobile App - Resident-facing workflows: authentication, profile management, maintenance complaints, facility booking, payment assistance

API Gateway Layer

ASP.NET Core Backend (5074) - Handles authentication, authorization, validation, agent orchestration, and database persistence

  • JWT authentication with role-based access control
  • Request validation and global error handling
  • Integration with AI agents via HTTP clients
  • Business rule enforcement
Agentic AI Layer
  • Safety Agent (8001) - Deterministic validation & approval workflows
  • Onboarding Agent (8002) - LLM-powered resident extraction
  • Maintenance Triage Agent (8000) - AI-powered complaint analysis & assignment
  • Payment Agent - Natural language payment queries & invoice assistance
Data Layer

PostgreSQL Database (Supabase)

  • Normalized relational schema
  • EF Core migrations for schema management
  • Audit fields on all tables (CreatedAt, UpdatedAt)
  • Indexes on frequently queried columns

Setup & Installation

Prerequisites

  • .NET 8 SDK
  • Node.js 18+ & npm
  • Flutter & Dart
  • Python 3.10+
  • PostgreSQL 14+ (or Supabase account)
  • Git

1. Clone Repository

git clone https://github.com/kavishka78/apartment-management-system.git
cd apartment-management-system

2. Backend Setup

cd backend/ApartmentManagement.Api

# Create .env file with database credentials
cat > .env << EOF
ConnectionStrings__DefaultConnection=Your_DB_Connection_String
Jwt__Key=Your_Secure_Key_Min_32_Chars
Jwt__Issuer=ApartmentHub
Jwt__Audience=ApartmentHubClients
SafetyAgentUrl=http://localhost:8001
OnboardingAgentUrl=http://localhost:8002
EOF

# Restore dependencies & apply migrations
dotnet restore
dotnet ef database update

# Run backend
dotnet run

3. Web App Setup

cd web/apartment-management-web

# Install dependencies
npm install

# Create .env.local
echo "VITE_API_BASE_URL=http://localhost:5074/api" > .env.local

# Start dev server
npm run dev

4. Python Agents Setup

# Safety Agent
cd agent-services/safety-agent
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --port 8001

# Onboarding Agent (in another terminal)
cd agent-services/onboarding-agent
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export GEMINI_API_KEY=your_key_here
python -m uvicorn main:app --port 8002

5. Flutter Mobile Setup

cd mobile

# Get dependencies
flutter pub get

# Create .env file
echo "API_BASE_URL=http://YOUR_API_IP:5074/api" > .env

# Run on emulator or device
flutter run

Environment Variables Required

  • DATABASE_URL - PostgreSQL connection string
  • GEMINI_API_KEY - Google Gemini API key (onboarding agent)
  • JWT_KEY - Secure key for JWT signing (min 32 chars)
  • STRIPE_SECRET_KEY - Stripe API secret key
  • FIREBASE_CREDENTIALS - Firebase service account JSON

Agentic AI Subsystem

The system features 4 specialized agents working in concert, each with defined responsibilities and controlled tool permissions.

🛡️ Safety Agent (Port 8001)
Running

Purpose: Deterministic validation gate for all high-risk operations

Key Features:

  • Schema validation (request structure checks)
  • Tenant isolation enforcement
  • Role-based permission checks
  • LKR 25,000 spend limit auto-approval
  • Injection attack pattern detection
  • Approval workflows for high-impact changes
  • 24 unit tests (100% passing)

POST /validate - Validate a proposed action

GET /verdicts - Retrieve validation history

POST /verdicts/{id}/decision - Record manager approval/rejection

📝 Onboarding Agent (Port 8002)
Running

Purpose: Extract resident details from free-form text with LLM + rules fallback

Key Features:

  • Google Gemini 3.8-Flash for natural language extraction
  • Regex fallback for structured "Label: value" text
  • Database-aware validation (duplicate emails, NIC formats)
  • Unit availability checking
  • Draft generation for manager review
  • 13 unit tests (100% passing)

POST /extract - Extract resident from text

POST /onboarding/draft - Generate validated draft with issues

⚙️ Maintenance Triage Agent (Port 8000)
Running

Purpose: Analyze maintenance complaints and recommend technician assignment

Key Features:

  • Complaint severity analysis
  • Category classification
  • Cost estimation
  • Technician skill matching
  • Priority assignment
💬 Payment Agent
Running

Purpose: Answer resident payment questions via natural language chat

Key Features:

  • Invoice explanation
  • Payment history queries
  • Outstanding balance tracking
  • Payment plan suggestions
  • Read-only access to financial data
